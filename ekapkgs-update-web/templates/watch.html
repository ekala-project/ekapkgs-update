Watch

Passive mode: repositories are indexed periodically and upstream feeds are polled for new releases.

How watch mode works
  1. Index. Each repository is evaluated with nix-eval-jobs; every package with a recognisable upstream source is recorded in the index.
  2. Bootstrap (observe only). The first poll after a package is indexed records the current upstream release as a baseline and dispatches nothing. Packages that were already behind upstream at that moment become backlog: outdated, but left for ekapkgs-update run.
  3. Poll. Later polls compare feeds against the baselines; only releases published after the bootstrap are dispatched as updates, each poll that dispatches creating a session.
